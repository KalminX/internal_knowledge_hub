🔌 Cloud Document Connectors & Ingestion Architecture

Production interface specifications for enterprise cloud storage synchronization with automated access control mapping.

GD

Google Drive Connector

OAuth 2.0 with Least-Privilege Scopes

Ready for Credentials
Required OAuth Scopes:
  • • https://www.googleapis.com/auth/drive.readonly
  • • https://www.googleapis.com/auth/drive.metadata.readonly
🔑 Configuration Parameters:

Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in environment.

MS

Microsoft SharePoint / Graph

Azure AD Application Permissions

Ready for Credentials
Required Microsoft Graph Permissions:
  • • Sites.Read.All (Application Scope)
  • • Files.Read.All (Delegated or App)
🔑 Configuration Parameters:

Set AZURE_TENANT_ID, AZURE_CLIENT_ID, and AZURE_CLIENT_SECRET in environment.

🔄 Synchronized Access-Control Ingestion Lifecycle

Cloud document imports preserve file modification timestamps, origin URLs, and document permissions. When a file is updated, restricted, or deleted in Google Drive or SharePoint, the connector synchronizes the update: old chunks are pruned immediately to prevent stale or unauthorized knowledge leakage.
